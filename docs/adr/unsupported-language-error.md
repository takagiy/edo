# 言語パッケージのないファイルはエラーにする

## 状況

標準の Read/Edit/Write を置き換えるには、どのファイルも扱えるのが理想。ただし構文木なしでは、edo の照合とインデント処理が成り立たない。

## 決定

拡張子に対応する言語パッケージがないファイルは `unsupported_language` エラーにする。

## 結果

- 得たもの: 照合の仕組みが 1 つで済み、構文を知らない照合が混ざらない。
- 失ったもの: JSON / YAML / TOML などの編集には標準ツールが引き続き要る。

## 採らなかった案

- テキストモード（ファイル全体を `@match.collapse` の 1 つの葉とみなす）: 後から足せるので v1 では入れない。
