# 書き込みは after を一度埋め込んでからファイル全体をパースし直して整える

## 状況

`after` のインデントを付け直したいが、複数行の文字列の中身は変えてはいけない。`after` は断片なので単独では判定できない。継ぎ目で `;` が重なる問題もある。

## 決定

1. 範囲を決め、`after` のインデントを単純にずらして埋め込み、差分パースする。
2. 継ぎ目に同じテキストの `@match.optional` の葉が並んだら、ファイル側を消す。
3. 埋め込んだ行の先頭が `@match.collapse` でない複数行の葉の内側にあれば、インデントを付け直さない。
4. 書き込み前後で ERROR / MISSING ノードを比べ、増えたものを `warnings.new_syntax_errors` で報告する。書き込みは拒否しない。

## 結果

- 得たもの: 完全なファイルの構文木で判定できる。`;` 専用の規則が要らない。構文の壊れにエージェントが往復なしで気づける。
- 失ったもの: 文字列の中身を独立した葉として持たない grammar では、3 の判定が効かない。

## 採らなかった案

- `after` だけをパースする: 断片なので判定が不確実。
