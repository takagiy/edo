# ボディの省略を言語によらない行単位の規則で行う

## 状況

`read` は関数のボディを省略してトークンを節約する。言語ごとにプレースホルダを設定させたくない。

## 決定

`@body` のノードについて次の規則を言語によらず適用する。

- 空白以外がすべてボディの中にある行は消す（行番号の飛びで省略を示す）。
- ボディと外側のコードが同じ行にあれば、ボディの部分を `...` に置き換える。
- ボディの最初と最後の子が名前のないノード（`{` `}` など）なら残す。
- `@doc` で定義に紐づいたノードは、ボディの中にあっても表示する。定義の範囲は doc を含む。
- 関数やメソッドが直接スコープに指定されたときだけ、そのボディを展開する。

## 結果

- 得たもの: 設定なしでどの言語でも動く。クラスの本体に `@body` を付けないことで、関数かどうかを edo が知る必要がない。
- 失ったもの: 省略は行番号の飛びでしか示されず、エージェントが気づかないことがある。

## 採らなかった案

- 言語ごとのプレースホルダ: 設定が増えるだけで得るものが少ない。
- 省略した行数を書き添える: トークンが増える。
