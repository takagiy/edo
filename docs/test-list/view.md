# 表示

- [x] 各表示行の前に行番号とタブが付く
- [x] 空白以外がすべてボディの中にある行は表示されない
- [x] ボディの外の空行は表示される
- [x] ボディと外側のコードが同じ行にあると、ボディの部分が、コードの `...` と見分けられる `…` になる
- [x] ボディの先頭と末尾の区切り記号は表示される
- [x] ボディの中の doc は表示される
- [x] 関数の定義を表示すると、そのボディは省略されない
- [x] 関数でない定義を表示すると、その中の関数のボディは省略される
- [x] 2000 文字を超える行は切り詰められ、残りの文字数が示される
- [x] 複数の定義を表示すると、間に空行が入る
