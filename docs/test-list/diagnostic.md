# 書き込みで増えたエラー

書き換えの対応（Hunk）、前のエラー、後のエラー、移す。構文エラーと LSP の診断の両方に使う。

- [x] 書き換えた箇所より前の行は、書き込み後も同じ行にある
- [x] 書き換えた箇所より後の行は、書き換えで増えた（減った）行数だけ移る
- [x] 書き換えた行は、書き込み後の行を持たない
- [x] 前と後で同じ文が同じ行（移した後）にあるエラーは、新しくない
- [x] 前にない文のエラーは、新しい
- [x] 同じ文でも、前のエラーと行が違う（移した後）エラーは、新しい
- [x] 書き換えた行にあった前のエラーは、比較に使わない
- [x] 2 か所を書き換えた書き込みでも、それぞれの箇所の後ろの行が正しく移る
- [x] 2 つのテキストの行の差分から、書き換えた箇所が求まる
- [x] 行の範囲を移すと、書き換えた行は、それに代わった行になる
- [x] 書き込みと整形のように 2 回続けて書き換えても、前のエラーは両方を通して移る
