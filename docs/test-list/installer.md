# インストーラー

`edo lang install` を引数なしで起動したときの対話画面。

- [x] 既知のレジストリごとに、見出しの下にパッケージが並ぶ
- [x] インストール済みのパッケージは選択された状態で始まる
- [x] 既知でないレジストリから入れたパッケージも、そのレジストリの見出しの下に並ぶ
- [x] 一度も取得していないレジストリには、未取得と表示される
- [x] 画面の最後に操作の説明が出る
- [x] カーソルは最初のパッケージから始まる
- [x] ↓ でカーソルは次のパッケージに移り、見出しは飛ばす
- [x] 最後のパッケージで ↓ を押してもカーソルは動かない
- [x] tab でカーソルのパッケージの選択が切り替わる
- [x] enter で、選択した未インストールのパッケージがインストール対象になる
- [x] enter で、選択を外したインストール済みのパッケージが削除対象になる
- [x] 確定すると、削除対象を消してからインストール対象を入れる
- [x] esc では何も変えずに終わる
- [x] 起動すると、一度も取得していないレジストリが取得される
- [x] U で既知のレジストリがすべて取得し直され、一覧が新しくなる
- [x] 取り直しても、選択とカーソルの位置は保たれる
- [x] 取得に失敗したレジストリは、画面の最後にエラーが出る
- [x] 取り直すと、画面の最後に、もう一度 U でインストール済みのパッケージを更新できると出る
- [x] 取り直した直後に U を押すと、インストール済みのパッケージの更新になる
- [x] 取り直した後に別のキーを押してから U を押すと、レジストリの取り直しになる
- [x] インストール済みのパッケージを更新すると、最新のコミットから入れ直される
- [x] インストール済みのパッケージを更新すると、画面の最後に更新したと出る
- [x] 取得中のレジストリは、見出しの右にスピナーが出る
- [x] 更新中のパッケージは、名前の右にスピナーが出る
- [x] スピナーはコマごとに次の形になる
- [x] 取得し終えたレジストリのスピナーは消える
