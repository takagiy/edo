# LSP クライアント

`crates/edo-lsp-client`。サーバー、文書、診断、覚え書き。

- [x] サーバーにつなぐと、initialize を送り、その応答の後に initialized を送る
- [x] initialize の応答が来る前の診断の問い合わせには、届かなかったと答える
- [x] 初めての文書は didOpen で渡し、その文書に届いた診断を返す
- [x] 覚えている内容と同じ文書の問い合わせには、サーバーに送らずに覚えている診断を返す
- [x] 覚えている内容と違う文書は didChange で渡し、新しい診断を返す
- [x] 待つ時間のうちに診断が届かなければ、届かなかったと答える
- [x] 別の文書の診断は、問い合わせた文書の診断として返さない
- [x] サーバーからの要求には応答を返す（workspace/configuration には項目の数だけ null を返す）
