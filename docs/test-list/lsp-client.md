# LSP クライアント

`crates/edo-lsp-client`。サーバー、文書、診断、覚え書き。

- [x] サーバーにつなぐと、initialize を送り、その応答の後に initialized を送る
- [x] initialize の応答が来る前の診断の問い合わせには、届かなかったと答える
- [x] 初めての文書は didOpen で渡し、その文書に届いた診断を返す
- [x] 覚えている内容と同じ文書の問い合わせには、サーバーに送らずに覚えている診断を返す
- [x] 覚えている内容と違う文書は didChange で渡し、新しい診断を返す
- [x] 待つ時間のうちに診断が届かなければ、届かなかったと答える
- [x] サーバーが終了していれば、閉じたと答える
- [x] 別の文書の診断は、問い合わせた文書の診断として返さない
- [x] ドライブ名の大文字と小文字だけが違う URI の診断も、その文書の診断として受け取る
- [x] サーバーからの要求には応答を返す（workspace/configuration には項目の数だけ null を返す）
- [x] 診断の要求に答えるサーバーには、didOpen と didChange のたびに textDocument/diagnostic を送り、その答えを返す
- [x] 答えを覚えている内容には、要求を送り直さない
- [x] 診断の要求に答えないサーバーには、要求を送らない
- [x] 古い内容への答えは、今の内容の診断として返さない
- [x] workspace/diagnostic/refresh を受けると、覚えている診断を捨てて要求し直す
- [x] 診断の要求を後から登録したサーバーには、要求を送る
- [x] 診断の要求の登録をすべて取り消したサーバーには、要求を送らない
- [x] workspace folder の変更に対応するサーバーには、フォルダーを足すと didChangeWorkspaceFolders を送り、そのフォルダーを受け持つ
- [x] workspace folder の変更に対応しないサーバーには、フォルダーを足せないと答え、何も送らない
- [x] 受け持っているフォルダーを足しても、通知を送らない
- [x] 保存の通知を求めるサーバーには、問い合わせた内容の文書を保存したと伝えると didSave を送る
- [x] 保存の通知を求めないサーバーには、didSave を送らない
- [x] 診断の要求に答えるサーバーからは、要求への答えと、送られてきた診断を合わせて返す
- [x] 開いていない文書に送られてきた診断も覚えていて、待たずに返せる
- [x] 内容を変えた文書について、前に送られてきた診断は捨てる
- [x] 整形するサーバーには textDocument/formatting を字下げの幅と種類を付けて送り、返ってきた編集を当てた内容を返す。編集の位置は UTF-16 で数える
- [x] 整形しないサーバーには要求を送らず、内容をそのまま返す
- [x] 整形を断ったサーバーからは、そのメッセージを返す
- [x] 整形の答えが間に合わなければ、間に合わなかったと返す
