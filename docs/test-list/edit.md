# 編集

- [x] 置換範囲が after に置き換わる
- [x] after の 1 行目は先頭の空白を除いて置換範囲の開始位置に入る
- [x] after の 2 行目以降は、最も浅い行が置換範囲の先頭行と同じ深さになる
- [x] after のインデントの単位はファイルの単位に換算される
- [x] 単位で割り切れないスペースは残る
- [x] 複数行の文字列の中の行はインデントが変わらない
- [x] `@match.collapse` の葉の中の行はインデントが付け直される
- [x] 継ぎ目に同じ optional の葉が並ぶと、ファイル側の葉が消える
- [x] CRLF のファイルは CRLF のまま書かれる
- [x] 行全体にまたがる置換範囲を空の after で置き換えると、その行が消える
- [x] 後ろへの挿入は置換範囲の次の行に入る
- [x] 前への挿入は置換範囲の先頭行の前に入る
- [x] 挿入した行は置換範囲の先頭行と同じ深さになる
- [x] 書き換えで増えた構文エラーが報告される
- [x] 書き換える前からあった構文エラーは報告されない
- [x] 書き換えた後の置換範囲の行が返される
