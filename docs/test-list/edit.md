# 編集

- [x] 置換範囲が after に置き換わる
- [x] after の 1 行目は先頭の空白を除いて置換範囲の開始位置に入る
- [x] 1 行目にインデントのない after の 2 行目以降は、最も浅い行が、置換範囲の 2 行目以降の最も浅い行と同じ深さになる。置換範囲が 1 行なら、先頭行と同じ深さになる
- [x] 行の途中から始まる置換範囲で、続きの行が先頭行より深い（メソッドチェーンや、行末の \ で続く文字列）と、その深さが保たれる
- [x] 閉じ括弧のない Python のメソッドを置き換えても、本体は def より深いまま
- [x] 1 行目にインデントのある after の 2 行目以降は、1 行目との深さの差を保つ
- [x] 1 行目より浅い after の行は、置換範囲の先頭行より浅くなる
- [x] after のインデントの単位はファイルの単位に換算される
- [x] 単位で割り切れないスペースは残る
- [x] 複数行の文字列の中の行はインデントが変わらない
- [x] `@match.collapse` の葉の中の行はインデントが付け直される
- [x] 継ぎ目に同じ optional の葉が並ぶと、ファイル側の葉が消える
- [x] CRLF のファイルは CRLF のまま書かれる
- [x] 改行コードが混ざったファイルで行を書き換えても、ほかの行の改行は変わらず、書いた行が正しく返される
- [x] 行全体にまたがる置換範囲を空の after で置き換えると、その行が消える
- [x] 後ろへの挿入は置換範囲の次の行に入る
- [x] 前への挿入は置換範囲の先頭行の前に入る
- [x] 挿入した行は置換範囲の先頭行と同じ深さになる
- [x] 書き換えた箇所の、前の行の範囲と、書いた後の行の範囲が返される
- [x] 複数バイトの文字で終わる置換範囲でも、前後の行の範囲が返される
- [x] ERROR か MISSING のノードが始まる行が、構文エラーになる
- [x] 書き換えた後の置換範囲の行が返される
- [x] after の先頭の空行は残る
- [x] 最後の行に改行がないファイルでも、その行の後ろに挿入できる
