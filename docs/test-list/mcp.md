# MCP

- [x] ツールの一覧は read と write を返す
- [x] read ツールは path と scope を受け取り、テキストを返す
- [x] write ツールは CLI と同じ MISON の報告を返す
- [x] 失敗した呼び出しの結果は isError が立つ
- [x] path には Windows の絶対パスを渡せる
- [x] 最後の read の後に変更されたファイルを行範囲で書くと、stale の警告が付く
- [x] stale の警告は、read と write でパスの書き方が違っても付く
- [x] edo 自身の write の後に行範囲で書いても、stale の警告は付かない
- [x] 識別子のスコープで書くときは、stale の警告は付かない
- [x] write ツールの `mode` で一致の後ろに挿入できる
- [x] read ツールは path と scope に加えて `path_0` `scope_0` のような番号付きの引数も読み、path の分の後に番号の順で並べる
- [x] glob で読んだ後に外で書き換えられたファイルに、行範囲のスコープで書くと、stale の警告が付く
- [x] 知らない引数を渡した呼び出しは、その引数の名前を挙げたエラーになり、何も書かない
- [x] 番号付きの引数の名前が知らないフィールドなら、その名前を挙げたエラーになる
- [x] 配列の `edits` や `reads` は、知らない引数としてエラーになる
- [x] write ツールは `path_0` `before_0` `after_0` のような番号付きの引数も 1 つの編集として受け取り、path の分の後に番号の順で書く
- [x] 番号付きの編集に `after_N` がないと、その番号を挙げたエラーになり、何も書かない
- [x] read と write のスキーマは、各フィールドの番号付きの名前を、パターンとして示す
- [x] 番号付きの `all_matches_N` は、文字列の "true" と "false" も真偽値として受け取る
- [x] `,` で区切ったスコープに行範囲が含まれ、最後の read の後にファイルが変更されていると、stale の警告が付く
- [x] read ツールの要素のどれかが失敗すると、残りの内容とエラーを返し、isError が立つ
