# スコープ

- [x] 名前 1 つのスコープは、どの深さにある同名の定義にも一致する
- [x] `.` で区切ったスコープは、親の並びが後ろから一致する定義にだけ一致する
- [x] `::` は `.` と同じ区切りとして扱われる
- [x] スコープ全体を 1 つの名前として持つ定義があれば、区切らずにそれに一致する
- [x] 数字だけのスコープはその 1 行を指す
- [x] `N-M` のスコープは N 行目から M 行目までを指す
- [x] 一致する定義がなければ not_found のエラーになる
- [x] ファイルの行数を超える行範囲は範囲外のエラーになる
- [x] `,` で区切ったスコープは、区切った順に、それぞれが指す範囲を指す
- [x] `,` を含むスコープ全体を名前に持つ定義があれば、区切らずにそれに一致する
- [x] `,` で区切ったスコープの 1 つでも解決できなければ、その部分を挙げたエラーになる
- [x] `,` で区切ったスコープの複数の部分が解決できなければ、エラーはそのすべての部分を挙げる
