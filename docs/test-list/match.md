# 照合

- [x] インデントの違う before が一致する
- [x] 改行の位置が違う before が一致する
- [x] 記号の前後の空白が違う before が一致する
- [x] 単語の葉が続く箇所に空白のない before は一致しない
- [x] 文字列の中身の空白が違う before は一致しない
- [x] 中身が空白で始まる文字列を含む before が一致する
- [x] 文字列の中身の先頭の空白が欠けた before は一致しない
- [x] 子ノードの間にあってどの子にも入らない文字も照合される
- [x] `@match.collapse` の葉は、中の空白の並びの長さが違っても一致する
- [x] `@match.optional` の葉が before になくても一致する
- [x] before にだけある optional のテキストは読み飛ばされる
- [x] `@match.trailing` の葉は、閉じ括弧の直前なら before になくても一致する
- [x] `@match.trailing` の葉は、閉じ括弧の直前でなければ省略できない
- [x] `@match.quote` の葉は、`alt` に挙げた別の引用符でも一致する
- [x] before の先頭は葉の後半部分に一致してよい
- [x] before の末尾は葉の前半部分に一致してよい
- [x] before の末尾は日本語の文の途中で終わってよい
- [x] before の末尾は識別子の途中では終わらない
- [x] before 全体が 1 つの葉の前半に収まっても一致する
- [x] 改行まで含む葉（Rust の doc コメント）は、改行を除いた 1 行だけの before に一致する
- [x] 一致はスコープの範囲の中でだけ探される
- [x] 一致が複数あればすべて返される
- [x] 一致がなければ、最も長く before を消費した位置が最も近い候補になる
- [x] 最も近い候補は、食い違った行と、期待したテキストと、見つかったテキストを持つ
- [x] 省略可能な葉が多くても、一致しない before の照合はすぐに終わる
