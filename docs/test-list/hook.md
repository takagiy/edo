# hook

`edo hook <ハーネス>:<イベント>` の判断と、ハーネスごとの入口と出口。

## 判断

- [x] 実行前に、対応言語のファイルを読む呼び出しは止められ、`mcp__edo__read` が理由になる
- [x] 実行前に、対応言語のファイルを編集する呼び出しは止められ、`mcp__edo__write` の `before` と `after` が理由になる
- [x] 実行前に、対応言語のファイルを書く呼び出しは止められ、ファイル全体を書く `mcp__edo__write` が理由になる
- [x] 実行前に、対応していないファイルへの呼び出しは通る
- [x] 実行前に、シェルの呼び出しは通る
- [x] 実行後に、対応言語のファイルを表示したシェルの呼び出しには、edo が使えるという文が添えられる
- [x] 実行後に、rtk が書き換えた `rtk read` で対応言語のファイルを表示した呼び出しにも、文が添えられる
- [x] 実行後に、`cd` などの後のコマンドで対応言語のファイルを表示した呼び出しにも、文が添えられる
- [x] 実行後に、表示するコマンドでないシェルの呼び出しには何も添えられない
- [x] 実行後に、対応していないファイルを表示したシェルの呼び出しには何も添えられない
- [x] 実行後に、読む・編集する・書く呼び出しには何も添えられない

## Claude Code の入口と出口

- [x] Read、Edit、Write の `tool_input.file_path` がその呼び出しのパスになる
- [x] Bash の `tool_input.command` がシェルの呼び出しになる
- [x] 止めるときは `permissionDecision: deny` と理由を返す
- [x] 添えるときは `additionalContext` を返す
- [x] 通すときは何も出力しない

## Codex の入口と出口

- [x] apply_patch の `*** Update File:` の行のファイルは、編集する呼び出しのパスになる
- [x] apply_patch の `*** Add File:` の行のファイルは、書く呼び出しのパスになる
- [x] 対応していないファイルだけの apply_patch は、何も出力せずに通す
- [x] Bash の `tool_input.command` がシェルの呼び出しになり、添えるときは `additionalContext` を返す
## 失敗

- [x] 読めない入力では、ハーネスの形で通す
- [x] 知らないハーネスやイベントでは、ハーネスの形で通す
