# インストール

- [x] 名前だけを指定すると、デフォルトのレジストリから探す
- [x] `<repo>:<name>` は指定したレジストリから探す
- [x] `owner/repo` は github.com のリポジトリを指す
- [x] URL のレジストリは最後の `:` で名前と分かれる
- [x] ルートの `[registry] packages` の glob でパッケージが列挙される
- [x] ルートが `[package]` のレジストリは、名前なしでインストールできる
- [x] `[registry]` と `[package]` が同じファイルにあるとエラーになる
- [x] パッケージは `<config>/edo/packages/<registry>/<name>/` に入る
- [x] インストールしたパッケージに入手元が記録される
- [x] 同じレジストリの同名パッケージを入れると上書きされ、前の入手元が報告される
- [x] 違うレジストリの同名パッケージは共存する
- [x] インストール済みのパッケージと拡張子が衝突するとエラーになる
- [x] 複数を指定すると、パッケージごとに結果が返る
- [x] 一覧には組み込みとインストール済みのパッケージが並ぶ
- [x] 削除するとパッケージのディレクトリが消える
- [x] 名前だけで複数のパッケージに当たると ambiguous になる
- [x] インストール済みのパッケージは言語として読み込まれる
