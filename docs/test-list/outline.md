# 定義の抽出

- [x] `@definition.*` のノードが定義になり、`@name` がその名前になる
- [x] 定義の前に紐づいた doc は定義の範囲に含まれる
- [x] 入れ子の定義は外側の定義を親に持つ
- [x] 見出しは定義の先頭行の前後の空白を除いたもの
- [x] 見出しの末尾の開き括弧は除かれる
- [x] 見出しは doc を飛ばした定義本体の先頭行から作る
- [x] `@body` を持つ定義は関数として扱われる
- [x] 名前のない定義は捨てられる
- [x] 別のパターンで同じノードに付けた doc と名前は 1 つの定義にまとまる
- [x] 空白だけを挟んで並ぶボディは 1 つのボディにまとまる
- [x] 定義の末尾まで空白しか残っていないボディは、その空白まで広がる
- [x] `@name` のない定義は `#set! name` の値を名前にする
