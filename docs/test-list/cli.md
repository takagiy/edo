# CLI

- [x] `<file>:<scope>` は最初の `:` でファイルとスコープに分かれる
- [x] スコープに `::` を含んでも最初の `:` で分かれる
- [x] `英字1文字:/` で始まる引数は、その `:` で分かれない
- [x] after に `-` を渡すと標準入力が after になる
- [x] 標準入力にコンフリクトマーカーがあれば before と after に分かれる
- [x] 標準入力にコンフリクトマーカーの組が複数あれば、組ごとに書き換える
- [x] read が成功するとテキストが出力され、終了コードは 0 になる
- [x] read は複数の対象を並べて受け取る
- [x] write の報告は MISON で出力される
- [x] 報告に失敗が含まれると終了コードは 1 になる
- [x] `--mode` を省くと一致を置き換える
- [x] `--mode insert-after-matches` は一致の後ろの行に挿入する
- [x] `--mode insert-before-matches` は一致の前の行に挿入する
- [x] `--mode` に未知の値を渡すと usage エラーになる
- [x] 位置引数が多すぎると usage エラーになる
- [x] after に `-` を渡して標準入力が空なら usage エラーになる
- [x] `ok` が `false` でない要素だけの報告は終了コード 0 になる
- [x] before を渡したうえでマーカー付きの標準入力を渡すと usage エラーになる
- [x] 端末でないところから `lang install` を引数なしで呼ぶと usage エラーになる
- [x] `hook` は標準入力の hook の入力に答えを出力し、終了コードは 0 になる
